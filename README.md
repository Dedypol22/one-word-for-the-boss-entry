One word for the boss: **Toddler**. He throws tantrums over small things, needs constant attention, cannot be left alone for five minutes, and makes messes that everyone else has to clean up. The moment you read it, you know exactly which boss it is — and that is the joke.

## Run it

```sh
python3 main.py
```

This writes `Toddler` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when `MAKEFUN_OUTPUT_DIR` is unset), after self-checking the competition rules: the word is non-empty, contains no whitespace, and is at most 30 characters long.
